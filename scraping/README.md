# Scraping notebooks

These notebooks are cleaned copies of the Python code I used during the thesis data collection.

They cover IMDb audience reviews, Rotten Tomatoes audience reviews and daily box-office tables from The Numbers. I kept them in the repository to show how the data collection was approached, but I have not tested them against the current websites and do not present them as maintained scraping tools.

The private movie lookup files and collected datasets are not included in the repository.
