# Data availability

The raw data used in the thesis are not included in this public repository.

This includes scraped review text and reviewer information, daily box-office extracts, the movie lookup files used during collection, budget/source data and the archived final analysis dataset. These files are kept under `data/private/` locally and are excluded from version control.

The historical review-volume source file is also not published because I no longer have a reliable record of its original collection step. The modelling script uses the private archived final thesis dataset so the original model inputs are preserved without recreating an undocumented process.

The public code is included to document the collection, preparation and modelling workflow.
